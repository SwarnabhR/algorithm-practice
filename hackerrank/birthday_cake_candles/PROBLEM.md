# Birthday Cake Candles

## Problem Statement

You are in charge of the cake for a child's birthday. It will have one candle
for each year of their total age. They will only be able to blow out the
tallest of the candles. Count how many candles are the tallest.

### Function Description

Complete the `birthdayCakeCandles` function with the following parameter:
- `candles`: the candle heights

**Returns**: the number of candles that are tallest.

### Input Format

The first line contains a single integer `n`, the size of `candles`.
The second line contains `n` space-separated integers, the heights of the candles.

### Output Format

Print a single integer: the number of candles that share the tallest height.

## Examples

### Example 0
- Input:
  ```
  4
  3 2 1 3
  ```
- Output:
  ```
  2
  ```
- Explanation:
  - The tallest candles are 3 units high. There are 2 candles with this height.
