# Solve Me First

## Problem Statement

Complete the `solveMeFirst` function to add two integers and return the result.

### Function Description

Complete the `solveMeFirst` function with the following parameter(s):
- `a`: first integer
- `b`: second integer

**Return**: the sum of the two integers

### Input Format

The first line contains an integer `a`.
The second line contains an integer `b`.

### Output Format

Return the sum `a + b`.

## Examples

### Example 1
- Input:
  ```
  2
  3
  ```
- Output: `5`
- Explanation: The sum of 2 and 3 is 5.

## Constraints

- `1 <= a, b <= 1000`

## Approach

Simple addition of two numbers.

## Complexity

- Time: O(1) — constant time
- Space: O(1) — constant space
